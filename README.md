# domashnyakuhnia
«Домашня кухня» — смак справжніх українських страв! 🇺🇦 Смачні домашні страви, борщі, вареники, млинці, сирники та багато інших смаколиків. Комплексні обіди за приємними цінами, доставка по місту та вигідні пропозиції для великих замовлень. Готуємо з любов’ю, щоб вам було смачно щодня! ❤️
